Controlled Load Test Procedure

A controlled 3-second load test measures open-circuit voltage ($V_{oc}$), applies a brief load to capture under-load voltage ($V_{load}$) and current ($I_{load}$), then computes real-world voltage sag and internal resistance ($R_{int}$).

Safety & Hardware Verification Checklist:

  • MOSFET Gate is connected to Arduino Pin 7 via 100 Ω series resistor and 10 kΩ pulldown.
  • Power resistor or load circuit is sized properly to dissipate the test current.
  • DS18B20 temperature sensor is secured against the cell body.
  • Cell is securely seated in battery holder with clean, low-resistance contacts.

Hardware Connection Troubleshooting Guide

Select an issue below for step-by-step diagnostic verification in beginner-friendly order.

1. INA219 sensor not detected on I2C bus (Address 0x40)
  1. Check SDA and SCL pin matching: On standard Arduino Uno Rev3, SDA is Pin A4 and SCL is Pin A5. Reversing these lines is the most common cause of bus initialization failure.
  2. Check Common Ground: Verify INA219 GND is firmly connected to an Arduino GND pin.
  3. Check VCC Supply: Ensure VCC is receiving 5V (or 3.3V) from the Arduino power header. Measure with a multimeter if available.
  4. Run I2C Scanner: Upload the standard Arduino IDE I2C scanner sketch. It should output I2C device found at address 0x40.
2. OLED SSD1306 display is blank or not detected
  1. Verify I2C Address: Most 0.96" OLED modules use address 0x3C, but some clone boards are hardwired to 0x3D.
  2. Check Parallel I2C Wiring: Both the OLED and INA219 share pins A4 (SDA) and A5 (SCL). Ensure breadboard jumper connections are not loose.
  3. Supply Voltage Compatibility: Most SSD1306 displays include an onboard 3.3V LDO regulator and can accept 5V, but cheap clones may require 3.3V.
3. DS18B20 temperature sensor not detected or reports -127 °C
  1. Check Pull-Up Resistor: The Dallas 1-Wire protocol requires a 4.7 kΩ resistor between the DATA line (Pin D7) and 5V. Without this resistor, readings float and return -127.0 °C.
  2. Check Pinout Orientation: Looking at the flat face of the TO-92 package with pins pointing down: Pin 1 (left) = GND, Pin 2 (center) = DATA (D7), Pin 3 (right) = VDD (5V). Reversing pins causes extreme heating!
  3. Check Firmware Pin Assignment: Verify that PIN_ONEWIRE in smartcell_arduino.ino is set to Digital Pin 7.
4. Invalid, floating, or unstable voltage readings (0.000 V to 0.450 V)
  1. Tighten Screw Terminals: High-resistance or loose screw terminals on the INA219 breakout cause voltage drop or floating inputs. Ensure stranded copper wire is securely clamped.
  2. Check Common Battery Ground: Sensed bus voltage is measured relative to INA219 GND. If the battery negative terminal does not connect to the Arduino GND, the ground reference is floating.
  3. Inspect Battery Holder Contacts: 18650 spring contacts frequently oxidize or have high contact resistance. Clean with isopropyl alcohol.
5. Serial COM Port unavailable or "Access Denied"
  1. Close Other Serial Monitors: On Windows, only one application can hold a COM port at a time. Close the Arduino IDE Serial Monitor, Cura, 3D printer host, or PuTTY.
  2. Disconnect & Re-plug USB: Unplug the Arduino USB-B cable, wait 3 seconds, and re-insert into a primary motherboard USB port.
  3. Check Device Manager: Open Windows Device Manager > Ports (COM & LPT) to confirm your Arduino is recognized as COM3, COM4, etc.
6. Arduino Uno disconnected or driver not recognized
  1. CH340 USB Chip Driver: If using a budget Arduino clone board, it uses a WCH CH340 USB-to-serial chip instead of an ATmega16U2. Download and install the CH341SER Windows driver.
  2. Verify Cable: Some micro-USB cables are power-only charging cables. Ensure you are using a data-sync USB-B or USB-C cable.
7. MOSFET load circuit marked NOT VALIDATED (Why?)
  1. Engineering Rationale: The website cannot electrically verify that your physical power resistor, heatsink, or fuse is safely sized before applying current. Premature automated activation creates fire hazards.
  2. Gate Threshold Verification: If using an IRF540N, verify gate drive voltage. With 5V logic from the Arduino, it will only conduct partially and run hot. A logic-level IRLZ44N is strongly recommended.
  3. Resistor Wattage Sizing: Verify power rating: $P = I^2 \times R$. For a 3.7V cell across 3.3 Ω ($I \approx 1.1\text{ A}$), power dissipation is $\approx 4\text{ W}$. Use at least a 10W power resistor with airflow!

Project Overview

Smart Battery Screening and Monitoring System

SmartCell — Smart Battery Screening and Monitoring System

SmartCell is an Arduino-based battery screening prototype designed to measure and monitor important battery parameters, including voltage, current, power, and temperature. The system aims to help users understand battery behavior and explore potential warning signs through measurements and controlled-load testing once the hardware has been safely validated.

Project Objectives

Core engineering goals and design targets for the battery screening prototype

1. Voltage Measurement

Measure open-circuit and loaded terminal bus voltage with millivolt resolution using the INA219 12-bit precision analog-to-digital converter.

2. Current & Power Monitoring

Monitor charge and discharge current across an onboard 0.1 Ω shunt resistor and compute instantaneous active power dissipation in milliwatts.

3. Battery Temperature

Measure cell surface temperature via a Dallas DS18B20 digital 1-Wire sensor to detect thermal stress, heating anomalies, and runaway risks.

4. Live Telemetry Visualization

Display valid live readings, connection indicators, and rolling waveform charts on the website when the device is actively communicating.

5. Voltage Sag & Recovery

Observe voltage sag during controlled 3-second load testing (Vsag = Voc − Vload) and post-test bounce-back once validated.

6. Warning Condition Detection

Identify potential warning signs, degraded health, and critical cutoff breaches using transparent, documented electrochemistry rules.

7. Historical Comparison

Record screening results locally with timestamps, battery chemistry presets, and RFC 4180 CSV export for lab reports and long-term comparisons.

Battery Screening Features

Live monitoring, impedance estimation, and safety heuristics

Live Voltage Monitoring

Tracks open-circuit voltage (Voc) and loaded bus voltage with automatic disconnect detection for values below 0.50 V.

Current & Power Tracking

Displays continuous current in amperes (converted accurately from mA) and calculates real-time power dissipation in mW.

Temperature Monitoring

Monitors thermal readings with overheat warnings triggered when cell temperature exceeds 45 °C. Shows “--” when disconnected.

Voltage Trend Charts

Renders rolling 30-sample time-series graphs of terminal voltage to visualize stability, noise, and discharge slope in real time.

Controlled-Load Sag Analysis

Quantifies instantaneous voltage sag (Vsag and sag percentage) during controlled 3-second pulse tests once hardware is validated.

Estimated Internal Resistance

Calculates DC internal resistance (Rint = ΔV / Iload in mΩ) only when valid open-circuit and loaded readings exist.

Standardized Health Status

Classifies cells into GOOD, WARNING, CRITICAL, or NOT TESTED based on transparent, configurable chemistry benchmark rules.

History & CSV Export

Stores completed screening runs in browser local storage with chemistry tags, date/time stamps, and one-click RFC 4180 CSV export.

Real-Time Connection Status

Maintains live connection indicators (Connected, Disconnected, Reconnecting) without showing stale measurements or fabricated values.
